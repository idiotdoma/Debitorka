## Исправленные проблемы

### 1. Проблема с входом в систему

**Симптом:** Пользователи не могли войти в систему через демо-аккаунты.

**Причина:** 
- В `seed.ts` пользователи создавались без обязательных полей модели `User`
- Отсутствовали поля: `firstName`, `lastName`, `isActive`, `updatedAt`
- Это вызывало ошибки валидации TypeScript и проблемы при входе

**Решение:**
- Обновлён файл `src/lib/seed.ts`
- Добавлены все обязательные поля для каждого пользователя:
  ```typescript
  {
    id: generateId('user'),
    email: 'admin@alfa.ru',
    passwordHash: hashPassword('admin123'),
    name: 'Иванов Иван',
    firstName: 'Иванов',
    lastName: 'Иван',
    organizationId: orgA.id,
    role: 'owner',
    isActive: true,
    createdAt: new Date().toISOString(),
    updatedAt: new Date().toISOString(),
  }
  ```
- Удалён дублирующий код обновления ролей (роли теперь задаются сразу при создании)

**Результат:** Все демо-пользователи теперь могут входить в систему.

### 2. Проблема с отображением демо-аккаунтов на странице входа

**Симптом:** На странице входа отображались неправильные email-адреса демо-аккаунтов.

**Причина:**
- В `LoginPage.tsx` показывались аккаунты с доменом `@demo.ru`
- В `seed.ts` создавались аккаунты с доменами `@alfa.ru` и `@beta.ru`

**Решение:**
- Обновлён файл `src/pages/LoginPage.tsx`
- Исправлены email-адреса в блоке "Демо-доступ":
  - `admin@alfa.ru` (Владелец, Орг. А)
  - `manager@alfa.ru` (Руководитель, Орг. А)
  - `employee@alfa.ru` (Сотрудник, Орг. А)
  - `admin@beta.ru` (Владелец, Орг. Б)
  - `viewer@beta.ru` (Наблюдатель, Орг. Б)

**Результат:** Пользователи видят правильные учётные данные для входа.

### 3. Проблема со скроллом боковой панели

**Симптом:** Боковая панель навигации не прокручивалась, нижние пункты меню были недоступны.

**Причина:**
- В `Layout.tsx` элемент `<nav>` не имел свойства `overflow-y-auto`
- При большом количестве пунктов меню они выходили за пределы видимой области

**Решение:**
- Обновлён файл `src/components/Layout.tsx`
- Добавлен класс `overflow-y-auto` к элементу навигации:
  ```tsx
  <nav className="flex-1 p-4 space-y-1 overflow-y-auto">
  ```

**Результат:** Боковая панель теперь прокручивается, все пункты меню доступны.

### 4. Ошибка инициализации функции в ReportsPage

**Симптом:** При открытии страницы "Отчёты" возникала ошибка:
```
Cannot access 'getReportTitle' before initialization
```

**Причина:**
- Функция `getReportTitle` объявлялась после места её использования
- В JavaScript/TypeScript функции, объявленные через `const`, не поднимаются (hoisting)
- Функция вызывалась внутри `useMemo` до её объявления

**Решение:**
- Обновлён файл `src/pages/ReportsPage.tsx`
- Переместил объявление функции `getReportTitle` перед `useMemo`:
  ```typescript
  export default function ReportsPage() {
    // ... state declarations ...
    
    // Функция объявлена ПЕРЕД использованием
    const getReportTitle = (type: ReportType): string => {
      const titles: Record<ReportType, string> = {
        registry: 'Общий реестр задолженности',
        overdue: 'Просроченная задолженность',
        // ...
      };
      return titles[type];
    };
    
    // Теперь useMemo может безопасно использовать getReportTitle
    const reportData = useMemo(() => {
      // ...
      const title = getReportTitle(reportType);
      // ...
    }, [/* dependencies */]);
  }
  ```

**Результат:** Страница "Отчёты" теперь открывается без ошибок.
