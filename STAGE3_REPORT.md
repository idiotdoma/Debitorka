## Механизм автоматических уведомлений

### Как работает
1. При загрузке приложения запускается `runNotificationChecks()`
2. Каждые 5 минут выполняется повторная проверка
3. Проверяются:
   - Просроченные задачи → уведомление `task_overdue`
   - Задачи со сроком в течение 24 часов → уведомление `task_due_soon`
   - Просроченные обещания → уведомление `promise_broken`
   - Обещания с наступившей датой → уведомление `promise_due`

### Идемпотентность
Каждое уведомление имеет `idempotencyKey`, который включает:
- Тип уведомления
- ID связанного объекта
- Дату

Это предотвращает создание дубликатов при повторных проверках.

### Часовой пояс
Используется часовой пояс организации (по умолчанию `Europe/Moscow`).

## Известные ограничения

1. **Нет серверной части** — вся логика на клиенте (localStorage). Для продакшена нужен серверный планировщик (cron, queue).
2. **Нет реальной очереди задач** — проверки выполняются синхронно при загрузке и по интервалу.
3. **Нет внешних каналов уведомлений** — только внутренние уведомления в приложении.
4. **Нет полной карточки контрагента** — только базовое управление контактами.
5. **Нет рабочего места руководителя** — базовая фильтрация задач, но нет агрегированной аналитики по сотрудникам.
6. **Нет истории изменений задач** — модель ActivityAudit создана, но не интегрирована в UI.
7. **Нет связи коммуникаций с задачами** — можно создать обещание из коммуникации, но нет автоматического создания задач.

## Инструкция по проверке

### 1. Запуск приложения
```bash
npm install
npm run dev
```

### 2. Вход в систему
- Email: `admin@alfa.ru`
- Пароль: `admin123`
- Роль: Руководитель

### 3. Создание задачи
1. Перейдите в раздел "Задачи"
2. Нажмите "Создать задачу"
3. Заполните поля:
   - Название: "Позвонить клиенту"
   - Тип: "Позвонить контрагенту"
   - Приоритет: "Высокий"
   - Срок: завтра
4. Нажмите "Создать задачу"

### 4. Проверка уведомлений
1. Создайте задачу со сроком вчера
2. Подождите 5 минут или перезагрузите страницу
3. Перейдите в "Уведомления"
4. Должно появиться уведомление о просроченной задаче

### 5. Рабочее место менеджера
1. Создайте несколько задач с разными сроками
2. Перейдите в "Мои задачи"
3. Проверьте KPI-карточки и списки

### 6. Tenant isolation
1. Выйдите из системы
2. Войдите как `admin@beta.ru` / `admin123`
3. Убедитесь, что задачи из организации А не видны

   - Перейдите в "Задачи" → "Создать задачу"
   - Название: "Проверить оплату от ООО Пример"
   - Тип: "Проверить обещанный платёж"
   - Приоритет: "Высокий"
   - Контрагент: "ООО Пример"
   - Срок: сегодня
   - Создайте задачу

2. **Запись контакта**
   - Перейдите в "Действия"
   - Выберите контрагента из списка
   - Нажмите "Добавить контакт"
   - Заполните:
     - Имя: "Иванов Иван"
     - Телефон: "+7 999 123-45-67"
     - Email: "ivanov@example.ru"
   - Сохраните

3. **Создание обещания оплаты**
   - (Функциональность обещаний доступна через API/store, UI для создания обещаний будет добавлен в следующем этапе)

4. **Проверка напоминания**
   - Создайте задачу со сроком вчера
   - Подождите 5 минут или перезагрузите страницу

   - Проверьте наличие уведомления о просроченной задаче
