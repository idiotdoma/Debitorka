## Известные ограничения

### Критические (требуют решения для production)
1. **Нет серверной части** - все данные в localStorage
2. **Нет серверной аутентификации** - клиентская проверка паролей
3. **Нет постоянной базы данных** - данные теряются при очистке браузера
4. **Нет реальной интеграции с 1С** - только модели данных

### Важные
1. **ИИ-помощник работает на правилах** - не использует LLM
2. **Нет фоновых задач** - уведомления только при открытии приложения
3. **Нет экспорта данных** - только импорт

### Незначительные
1. **Размер бандла > 500 kB** - рекомендуется code splitting
2. **Нет тестов** - тесты не восстановлены из репозитория
