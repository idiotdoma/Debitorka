## 🧪 Как проверить соединение с Supabase

### Шаг 1: Создайте файл `.env.local`

В корне проекта создайте файл `.env.local`:

```env
VITE_SUPABASE_URL=https://your-project-id.supabase.co
VITE_SUPABASE_PUBLISHABLE_KEY=your-publishable-key-here
```

**Где взять значения:**
1. Откройте https://supabase.com/dashboard/
2. Выберите ваш проект
3. Перейдите в **Settings** → **API**
4. Скопируйте:
   - **Project URL** → `VITE_SUPABASE_URL`
   - **Project API keys** → **publishable key** → `VITE_SUPABASE_PUBLISHABLE_KEY`

⚠️ **Важно:** Используйте только **publishable key** (anon key). Никогда не используйте **secret key** (service role key) во frontend!

### Шаг 2: Проверьте инициализацию клиента

Добавьте временный код для проверки в `src/main.tsx`:

```typescript
import { isSupabaseConfigured, supabase } from './lib/supabase';

console.log('Supabase configured:', isSupabaseConfigured);
if (supabase) {
  supabase.auth.getSession().then(({ data }) => {
    console.log('Supabase session:', data.session);
  });
}
```

### Шаг 3: Запустите приложение

```bash
npm run dev
```

Откройте консоль браузера (F12) и проверьте:
- `Supabase configured: true` - клиент инициализирован
- `Supabase session: null` - пользователь не авторизован (это нормально)

### Шаг 4: Проверьте подключение к базе данных

Добавьте тестовую функцию в компонент:

```typescript
import { supabase } from '../lib/supabase';

async function testConnection() {
  if (!supabase) {
    console.error('Supabase not configured');
    return;
  }
  
  try {
    // Попробуем получить данные из таблицы profiles
    const { data, error } = await supabase
      .from('profiles')
      .select('count')
      .limit(1);
    
    if (error) {
      console.error('Database error:', error);
      return;
    }
    
    console.log('Connection successful!');
  } catch (err) {
    console.error('Connection failed:', err);
  }
}
```
