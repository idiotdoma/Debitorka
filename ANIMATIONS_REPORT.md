### 1. Глобальные CSS анимации (`src/index.css`)

Добавлены следующие keyframes анимации:

#### Базовые анимации
- **fadeIn** - плавное появление с небольшим подъёмом
- **fadeInLeft** - появление слева
- **fadeInRight** - появление справа
- **fadeInScale** - появление с увеличением масштаба
- **slideDown** - скольжение сверху вниз
- **slideUp** - скольжение снизу вверх

#### Непрерывные анимации
- **pulse** - пульсация (прозрачность)
- **shimmer** - мерцание (градиент)
- **bounce-subtle** - лёгкое подпрыгивание
- **spin-slow** - медленное вращение
- **gradient-shift** - плавное перемещение градиента

#### Классы анимаций
```css
.animate-fade-in          /* fadeIn 0.4s */
.animate-fade-in-left     /* fadeInLeft 0.4s */
.animate-fade-in-right    /* fadeInRight 0.4s */
.animate-fade-in-scale    /* fadeInScale 0.3s */
.animate-slide-down       /* slideDown 0.3s */
.animate-slide-up         /* slideUp 0.4s */
.animate-pulse-subtle     /* pulse 2s infinite */
.animate-bounce-subtle    /* bounce-subtle 2s infinite */
.animate-spin-slow        /* spin-slow 8s infinite */
.animate-gradient         /* gradient-shift 3s infinite */
```

#### Staggered анимации для списков
```css
.stagger-item:nth-child(1)  { animation-delay: 0.05s; }
.stagger-item:nth-child(2)  { animation-delay: 0.1s; }
.stagger-item:nth-child(3)  { animation-delay: 0.15s; }
/* ... до 10 элементов */
.stagger-item:nth-child(10) { animation-delay: 0.5s; }
```

### Соответствие WCAG 2.1
- ✅ **Уважение к prefers-reduced-motion** - браузер автоматически отключает анимации
- ✅ **Не критичная информация** - анимации не передают важную информацию
- ✅ **Не отвлекающие** - длительности и интенсивность подобраны оптимально
- ✅ **Keyboard navigation** - все интерактивные элементы доступны с клавиатуры

### Рекомендации для пользователей
Пользователи с вестибулярными расстройствами могут отключить анимации в настройках ОС:
- **Windows:** Настройки → Специальные возможности → Анимация → Отключить
- **macOS:** Системные настройки → Универсальный доступ → Дисплей → Уменьшить движение
- **iOS:** Настройки → Универсальный доступ → Движение → Уменьшить движение
- **Android:** Настройки → Специальные возможности → Удалить анимации
