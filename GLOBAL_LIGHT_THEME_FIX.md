## Решение

### Глобальные CSS правила

Вместо исправления каждого файла вручную, добавлены глобальные CSS правила в `src/index.css`, которые автоматически переопределяют цвета для светлой темы.

#### 1. Переопределение цветов текста

```css
:root:not(.dark) {
  /* Заголовки и основной текст */
  h1, h2, h3, h4, h5, h6,
  .text-white,
  .text-white\/60,
  .text-white\/70,
  .text-white\/80,
  .text-white\/90 {
    color: #1e293b !important;
  }
  
  /* Вторичный текст */
  .text-blue-200\/60,
  .text-blue-300\/50,
  .text-white\/40,
  .text-white\/50 {
    color: #64748b !important;
  }
  
  /* Акцентные цвета */
  .text-blue-300, .text-blue-400 { color: #3b82f6 !important; }
  .text-green-300, .text-green-400 { color: #10b981 !important; }
  .text-red-300, .text-red-400 { color: #ef4444 !important; }
  .text-yellow-300, .text-yellow-400 { color: #f59e0b !important; }
  .text-purple-300, .text-purple-400 { color: #8b5cf6 !important; }
  .text-orange-300, .text-orange-400 { color: #f97316 !important; }
}
```

#### 2. Переопределение фонов

```css
:root:not(.dark) {
  /* Фоны для карточек и контейнеров */
  .bg-white\/5,
  .bg-white\/10,
  .bg-white\/20 {
    background-color: #ffffff !important;
    border-color: #e2e8f0 !important;
  }
  
  /* Границы */
  .border-white\/5,
  .border-white\/10,
  .border-white\/20 {
    border-color: #e2e8f0 !important;
  }
  
  /* Backdrop blur элементы */
  .backdrop-blur {
    background-color: #ffffff !important;
  }
  
  /* Градиенты */
  .bg-gradient-to-br.from-slate-900 {
    background: linear-gradient(to bottom right, #f8fafc, #eef2ff) !important;
  }
}
```

#### 3. Переопределение форм

```css
:root:not(.dark) {
  /* Inputs и selects */
  input, select, textarea {
    background-color: #ffffff !important;
    border-color: #cbd5e1 !important;
    color: #1e293b !important;
  }
  
  input::placeholder, textarea::placeholder {
    color: #94a3b8 !important;
  }
  
  /* Options в select */
  option {
    background-color: #ffffff !important;
    color: #1e293b !important;
  }
}
```

## Как это работает

### Селектор `:root:not(.dark)`

Этот селектор применяется **только когда на `<html>` нет класса `dark`**, то есть в светлой теме.

**Светлая тема:**
```html
<html class="light">
  <!-- Применяются правила :root:not(.dark) -->
</html>
```

**Тёмная тема:**
```html
<html class="dark">
  <!-- Правила :root:not(.dark) НЕ применяются -->
  <!-- Работают обычные классы Tailwind с dark: префиксом -->
</html>
```

### Приоритет с `!important`

Используется `!important` для гарантированного переопределения классов Tailwind. Это необходимо, потому что:
1. Классы Tailwind генерируются с высокой специфичностью
2. Глобальные правила должны иметь приоритет
3. Это временное решение до полного рефакторинга всех компонентов

