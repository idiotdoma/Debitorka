## Архитектурные особенности

### Календарный режим

**Структура данных:**
- `calendarDays` - массив объектов `{ date: Date, isCurrentMonth: boolean }`
- Генерируется для текущего месяца с днями предыдущего/следующего месяца
- Используется CSS Grid с 7 колонками (понедельник - воскресенье)

**Отображение событий:**
- Для каждого дня вызывается `getEventsForDay(date)`
- Возвращает `{ dueDebts: [], promises: [], overdue: [] }`
- Отображается до 2 событий каждого типа
- Если событий больше, показывается индикатор "+N ещё"

**Навигация:**
- Кнопки "←" и "→" для переключения месяцев
- `currentDate` хранит текущий отображаемый месяц
- Календарная сетка пересчитывается при изменении `currentDate`

### Отчёт по обещаниям

**Структура данных:**
- Используется `promiseStore.getAll()` для получения всех обещаний
- Маппинг данных с форматированием дат и сумм
- Колонки: контрагент, контакт, дата, сумма, статус, источник, комментарий

**Экспорт:**
- CSV: защита от формульных инъекций, экранирование кавычек
- XLSX: использование библиотеки xlsx для генерации файла
