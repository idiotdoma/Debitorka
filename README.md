## Известные ограничения

1. **Нет серверной части** — tenant isolation на клиенте (localStorage). Для продакшена нужен серверный middleware.
2. **Нет серверной аутентификации** — используется клиентская имитация JWT.
3. **Нет реальной БД** — все данные в localStorage. При очистке браузера данные теряются.
4. **Нет индексации** — фильтрация на клиенте. При >10 000 записей нужна серверная пагинация.
