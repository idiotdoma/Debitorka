## Архитектурные блокеры перед commercial use

### Критические

1. **Нет backend API**
   - Текущее состояние: вся логика на клиенте
   - Проблема: нельзя безопасно хранить API-ключи
   - Решение: реализовать серверный API для ИИ

2. **Нет серверной аутентификации**
   - Текущее состояние: клиентская имитация JWT
   - Проблема: можно подделать сессию
   - Решение: серверная аутентификация (Supabase Auth, Auth0)

3. **Нет защиты данных на уровне backend**
   - Текущее состояние: tenant isolation на клиенте
   - Проблема: можно обойти через DevTools
   - Решение: серверный middleware для проверки доступа

### Важные

4. **Нет rate limiting**
   - Текущее состояние: нет ограничений запросов
   - Проблема: бесконтрольное расходование токенов
   - Решение: серверный rate limiter

5. **Нет мониторинга использования токенов**
   - Текущее состояние: только локальное логирование
   - Проблема: нет контроля расходов
   - Решение: серверное логирование с метриками

## Ограничения демонстрационного режима

1. **Mock-провайдер** — ответы генерируются локально по шаблонам
2. **Нет реального ИИ** — нет интеграции с OpenAI/Anthropic
3. **Нет серверной части** — нельзя безопасно использовать API-ключи
4. **Ограниченная аналитика** — базовые шаблоны вместо полноценного ИИ

## Инструкция по проверке

### 1. Запуск приложения
```bash
npm install
npm run dev
```

### 2. Вход в систему
- Email: `admin@alfa.ru`
- Пароль: `admin123`

### 3. Доступ к ИИ-помощнику
- Перейдите в раздел "ИИ-помощник" в меню
- Выберите функцию (анализ, письмо, приоритеты, план, история, вопрос)
- Выберите контрагента (если требуется)
- Нажмите кнопку выполнения

### 4. Проверка функций

#### Анализ контрагента
1. Выберите "Анализ контрагента"
2. Выберите контрагента из списка
3. Нажмите "Анализировать"
4. Проверьте результат: сводка, факты, рекомендации

#### Генерация письма
1. Выберите "Подготовить письмо"
2. Выберите контрагента
3. Выберите тип письма, тон, формат
4. Нажмите "Сгенерировать письмо"
5. Проверьте черновик

#### Объяснение приоритетов
1. Выберите "Объяснить приоритеты"
2. Нажмите "Анализировать приоритеты"
3. Проверьте список приоритетных задолженностей

#### План на день
1. Выберите "План на день"
2. Нажмите "Составить план"
3. Проверьте список задач на сегодня

#### Сводка истории
1. Выберите "Сводка истории"
2. Выберите контрагента
3. Нажмите "Сформировать сводку"
4. Проверьте историю работы с контрагентом

#### Вопросы к данным
1. Выберите "Задать вопрос"
2. Введите вопрос (например, "Какая общая задолженность?")
3. Нажмите "Спросить"
4. Проверьте ответ

### 5. Проверка безопасности
1. Выйдите из системы
2. Войдите как `admin@beta.ru` / `admin123`
3. Попробуйте проанализировать контрагента из организации А
4. Должна появиться ошибка "FORBIDDEN"
