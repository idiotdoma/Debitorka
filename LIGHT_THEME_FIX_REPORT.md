# Исправление контрастности в светлой теме

## Дата исправления
2026-03-29

## Проблема
Пользователь сообщил, что текст в светлой теме совершенно нечитабельный.

## Причина
Компоненты использовали условные классы на основе переменной `isLight`, которая определялась через `document.documentElement.classList.contains('light')`. Этот подход имел несколько проблем:

1. **Класс `light` не добавлялся при первой загрузке** - ThemeContext добавлял класс только в `useEffect`, который выполняется после рендера
2. **Условные классы были громоздкими** - каждый элемент требовал проверки `isLight ? 'class1' : 'class2'`
3. **Непоследовательное применение** - некоторые компоненты использовали условные классы, другие - нет

## Решение

### 1. Обновление ThemeContext
Добавлен второй `useEffect` для установки класса темы при первой загрузке:

```typescript
// Устанавливаем тему при первой загрузке
useEffect(() => {
  document.documentElement.classList.add(theme);
}, []);
```

### 2. Переход на CSS классы Tailwind `dark:`
Вместо условных классов на основе `isLight` теперь используются стандартные классы Tailwind с префиксом `dark:`:

**Было:**
```typescript
const isLight = document.documentElement.classList.contains('light');
<h1 className={`${isLight ? 'text-gray-900' : 'text-white'}`}>
```

**Стало:**
```typescript
<h1 className="text-gray-900 dark:text-white">
```

### 3. Обновление CSS переменных
Улучшена контрастность текста в светлой теме:

```css
:root {
  --text-primary: #1e293b;  /* Было: #0f172a */
  --text-secondary: #475569;
  --text-tertiary: #64748b;
  --text-muted: #94a3b8;
}
```

## Рекомендации для будущих компонентов

При создании новых компонентов всегда используйте:

1. **Классы Tailwind с `dark:` префиксом:**
   ```typescript
   className="text-gray-900 dark:text-white"
   ```

2. **CSS переменные для сложных случаев:**
   ```typescript
   style={{ color: 'var(--text-primary)' }}
   ```

3. **Не используйте условные классы на основе `isLight`:**
   ```typescript
   // ❌ Плохо
   const isLight = document.documentElement.classList.contains('light');
   className={isLight ? 'text-black' : 'text-white'}
   
   // ✅ Хорошо
   className="text-gray-900 dark:text-white"
   ```

4. **Тестируйте в обеих темах:**
   - Переключайте тему через кнопку в боковой панели
   - Проверяйте контрастность текста
   - Проверяйте видимость границ и иконок
